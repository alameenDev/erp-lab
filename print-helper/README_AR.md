# Digital Lab Print — مساعد الطباعة لـ Windows

برنامج مستقل لاختيار طابعة محفوظة لكل نوع من مستندات Digital Lab. لا يحتاج QZ Tray أو اشتراك خدمة طباعة. يعمل مع الطابعات المثبتة في Windows، سواء USB أو طابعة شبكة يعرفها النظام.

## التثبيت والربط

1. نزّل `Digital-Lab-Print-Setup-1.0.0.exe` من مخرجات فحص **Digital Lab Print helper** في طلب الدمج، أو من مسؤول النظام. طابق SHA256 مع الملف المرفق عند توزيع المثبّت.
2. شغّل المثبّت للمستخدم الحالي ثم افتح **Digital Lab Print**. الإصدار الأول غير موقّع بشهادة ناشر تجارية؛ قد يعرض Windows تنبيهاً عن الناشر. لا تعطّل حماية Windows؛ التوقيع التجاري خيار للتوزيع الواسع لاحقاً.
3. اختر «إنشاء رمز ربط». الرمز صالح لخمس دقائق ولمرة واحدة.
4. داخل الموقع افتح **الطابعات لهذا الجهاز** من قائمة الحساب، أو من إعدادات المختبر. أدخل الرمز، ثم راجع عنوان الموقع ووافق عليه في نافذة المساعد.
5. اسمح بإذن **الاتصال بالشبكة المحلية / Loopback** إذا طلب Chrome أو Edge ذلك. لا يحتاج المساعد فتح منفذ على الراوتر أو تعطيل حماية المتصفح.
6. اختر طابعة لكل نوع، واطبع تجربة، ثم فعّل الطباعة المباشرة واضغط **حفظ اختيارات الطابعات**. اترك النوع على «نافذة الطباعة الاعتيادية» إذا لا تريد تحويله للمساعد.
7. إذا ترغب، فعّل تشغيل المساعد عند الدخول إلى Windows من نافذته. إغلاق النافذة يبقيه بجانب الساعة؛ «إنهاء» يوقفه.

الاختيارات محفوظة لهذا المتصفح على هذه الحاسبة. حاسبة جديدة أو متصفح جديد يحتاج إعداداً مستقلاً. مسح بيانات الموقع يمسح الاختيارات والربط. الربط مجدداً لنفس الموقع يستبدل الرمز السابق.

## الأنواع المشمولة

| النوع | ما يرسله المساعد |
|---|---|
| الباركود | نفس SVG ونفس رقم العينة، رقم سجل العمل الاختياري، المقاس وعدد ملصقات كل عينة |
| التقارير الطبية | نفس صفحات A4 المركّبة، بما فيها الخلفية والمرفقات المحوّلة إلى صفحات |
| الفاتورة | نفس إعدادات A4/A5 والاتجاه والهوامش |
| الوصل الحراري | عرض 58 أو 80 مم حسب المستند وطول مقاس للمحتوى |
| أمر العمل وورقة العمل | نفس المحتوى والاختيارات والخلفية والهوامش |
| سجل نتائج المريض | نفس جدول النتائج السابق |
| سجل العمل اليومي | نفس سجل اليوم المختار والمجموع، A4 أفقي |

عدد النسخ في الإعدادات يكرر المستند كاملاً. للباركود، اتركه **1** عند استخدام أعداد ملصقات مستقلة لكل عينة. ورقة تجربة إعداد طابعة الباركود 50 × 30 مم؛ استخدم أيضاً تجربة مصمم الملصقات للتحقق من مقاس ملصقات مختبرك الفعلي.

## الحفاظ على العمل الحالي

- الميزة مغلقة افتراضياً. لا اتصال محلي ولا تغيير على مسار الطباعة ما لم تُربط وتُفعّل وتُحدّد طابعة لذلك النوع.
- تنزيل PDF والمعاينة والإرسال إلى WhatsApp لا تمر بالمساعد.
- إعدادات المختبر وقاعدة البيانات لم تتغير، ولا يوجد ترحيل قاعدة بيانات.
- زر **العودة للطباعة الاعتيادية** يوقف التحويل فوراً ويحفظ الاختيارات لإعادة استخدامها.
- إذا تعذر الاتصال أو تجهيز صورة **قبل إرسال الطلب**، يعرض الموقع خيار فتح نافذة الطباعة الاعتيادية.
- بعد بدء الإرسال، لا يعاد إرسال الطلب أو فتح طباعة ثانية تلقائياً. عند عدم تأكد الحالة، راجع قائمة طباعة Windows والأوراق الخارجة قبل إعادة الطباعة.
- قبول Windows للطلب يعني وصوله إلى قائمة الطباعة، وليس دليلاً أن الورق خرج؛ انقطاع الطابعة أو نفاد الورق يعالج من Windows/الطابعة.
- إذا غُيّر اسم الطابعة أو حُذفت، اختر الاسم الجديد. لا ينتقل البرنامج تلقائياً إلى طابعة مختلفة.
- المستند الذي يعتمد على ملف تنسيق خارجي، أو تتعذر قراءة إحدى صوره، يرجع لاختيار الطباعة الاعتيادية بدلاً من إرسال مستند ناقص.

## التشغيل والصيانة

الاتصال محلي فقط إلى `127.0.0.1:17891`. لا تفتح هذا المنفذ على الشبكة. الربط يتطلب رمزاً وموافقة محلية، ثم رمز وصول خاصاً بعنوان الموقع. يمكن إلغاؤه من الموقع أو نافذة المساعد.

المساعد لا يحتفظ بملفات المرضى. سجل منع تكرار الطلبات يحتفظ بمعرّف عشوائي وبصمة وحالة الطلب فقط، بلا محتوى التقرير أو اسم المريض. قائمة Windows نفسها تخضع لإعدادات الطابعة والنظام. لا يُشغّل JavaScript المرسل داخل المستند، ولا يُسمح له بالوصول للملفات أو الإنترنت.

اختبر أولاً على حاسبة واحدة: باركود فعلي يُقرأ بجهاز المسح، تقرير متعدد الصفحات ومرفقات، فاتورة A4/A5، وصل 58/80 مم، أمر/ورقة عمل وسجل يومي. راجع المقاسات والهوامش والألوان وإعداد تعريف كل طابعة. فحوص CI تتحقق من المستندات وقراءة الباركود من PDF؛ اختبار الطابعة المادية يبقى ضرورياً قبل التعميم.

## البناء من المصدر

المتطلبات: Node.js 22+، Windows 10/11 x64، npm.

```sh
cd print-helper
npm ci
npm test
npm start
npm run smoke
npm run build:win
```

المثبّت في `print-helper/dist/`. فحص GitHub يبني المثبّت ويفحص تشغيل النسخة المجمّعة. لا توجد عملية نشر أو تحديث تلقائي. وزّع المثبّت من مصدر Digital Lab المعتمد، وحدّث Electron دورياً.

لإظهار زر تحميل داخل الموقع، اضبط `VITE_PRINT_HELPER_DOWNLOAD_URL` إلى رابط HTTPS لملف المثبّت الذي توزعه، ثم أعد بناء الواجهة. إذا لم يُضبط، توضح الشاشة اسم الملف وتطلب الحصول عليه من مسؤول Digital Lab.

Electron وelectron-builder لهما تراخيص مفتوحة المصدر؛ يحتفظ المثبّت بإشعارات مكوناته. البرنامج الخاص بالمشروع ليس إعادة توزيع لكود QZ Tray.
