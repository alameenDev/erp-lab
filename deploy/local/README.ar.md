# تشغيل محلي تجريبي — Windows 11

هذه الحزمة تشغّل واجهة المشروع وLaravel وMariaDB على الحاسبة الرئيسية.
**ليست نسخة مزامنة، ولا تنقل البيانات الموجودة على هوستنكر. لا تدخل بيانات مرضى حقيقية فيها قبل إكمال النقل والمزامنة واختبارهما.**

## تشغيل أول مرة

شغّل Docker Desktop. افتح PowerShell داخل مجلد المشروع ثم نفّذ:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\local\Start-LocalLab.ps1
```

خيار ExecutionPolicy يخص جلسة تشغيل هذا الملف فقط، ولا يغيّر سياسة ويندوز الدائمة.
التشغيل الأول يحتاج الإنترنت لتنزيل الصور والاعتماديات والبناء. يُنشئ البرنامج إعدادات محلية عشوائية في `.env.local` ولا يستبدلها عند إعادة التشغيل. احتفظ بالملف محلياً ولا ترسله لأحد.

بعد ظهور Local trial ready، أنشئ حساب مدير تجريبي:

```powershell
docker compose --env-file .env.local -f deploy/local/compose.yaml exec app php artisan erp:install
```

أجب yes ثم أدخل اسم المدير والبريد وكلمة مرور من 12 حرفاً على الأقل. هذه قاعدة منفصلة تماماً عن هوستنكر.
افتح http://localhost:8080 . لا تستعمل بيانات الدخول السحابية؛ لم تُنقل حساباتها إلى هنا.

## التشغيل بعد البناء بدون إنترنت

```powershell
docker compose --env-file .env.local -f deploy/local/compose.yaml up -d --no-build --pull never
```

لإيقاف الحزمة مع الاحتفاظ بالبيانات:

```powershell
docker compose --env-file .env.local -f deploy/local/compose.yaml stop
```

تُحفظ قاعدة البيانات والمرفقات في Docker volumes. إعادة تشغيل الحاويات لا تمسحها. حذف volumes أو Factory Reset في Docker يمسحها؛ وهي ليست نسخة احتياطية. لا تستخدم `down -v` على بيانات تريد الاحتفاظ بها.

## حدود هذه المرحلة

- الوصول محصور بالحاسبة الرئيسية (127.0.0.1)، إلى أن تُجهَّز شبكة المختبر وHTTPS.
- المزامنة مع هوستنكر، نقل البيانات القديمة، التشغيل التلقائي بعد إعادة تشغيل ويندوز، والنسخ الاحتياطي المجدول لم تُنفَّذ بعد.
- روابط بوابة المريض المحلية لا تعمل خارج هذه الحاسبة. واتساب والبريد والخدمات الخارجية تحتاج الإنترنت.
- الخطوط والصور الخارجية قد تستخدم بدائل محلية عند انقطاع الإنترنت؛ يجب مراجعة المطبوعات محلياً.
- قبل التشغيل الفعلي: نقل نسخة متسقة من البيانات والمرفقات ومفتاح التطبيق، تحديد مصدر واحد للتعديل، ثم اختبار انقطاع وعودة الإنترنت وعدم تكرار الفواتير والنتائج وحركات المخزون والنقاط.
