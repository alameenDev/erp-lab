# مراقبة نتائج الأجهزة

- من **التقارير الطبية**، زر **جميع نتائج الأجهزة** بجانب إعدادات المختبر يفتح شاشة الأجهزة على جميع الإرسالات: المعلقة، المطابقة، المنقولة والمتعثرة.
- تبويب **نتائج معلقة** يعرض المعلقة والمطابقة بانتظار النقل فقط. تبويب **جميع نتائج الأجهزة** يعرض السجل الكامل عبر صفحات، بما فيه إرسالات الأجهزة المحذوفة داخل المختبر نفسه.
- كل إرسال يعرض اسم المريض المرتبط بالفاتورة، باركود العينة كما وصل مع الاحتفاظ بالأصفار في بدايته، الجهاز، عدد القيم، حالة النقل ووقت الاستلام. عدد الإرسالات ليس عدد المرضى؛ إعادة الإرسال قد تنتج أكثر من سجل للمريض نفسه.
- البحث بالاسم أو باركود العينة أو باركود الفاتورة، مع تحديد الحالة والجهاز ثم الضغط على **بحث**. التحديث التلقائي كل 30 ثانية يحافظ على البحث والصفحة الحالية، ويتوقف عند مغادرة الشاشة أو إخفاء نافذة المتصفح. زر التحديث يعيد تحميل البحث الحالي.
- **تفاصيل النتيجة** يعرض المريض والباركود المستلم وباركود الفاتورة المرتبطة، أوقات الاستلام والنقل، القيم والوحدات والمديات والعلامات، تحذيرات الجهاز وتعليقاته، معرّفات العينة والرسالة الأصلية. النصوص تظهر كنص آمن، ولا تنفذ HTML أو JavaScript.
- عند عدم وجود فاتورة مرتبطة يظهر **غير مرتبط بمريض**؛ لا يُخمن اسم مريض من باركود مكرر أو من مختبر آخر. وإذا الفاتورة موجودة والاسم غير متوفر يظهر ذلك بوضوح. السجلات المحذوفة تاريخياً تحمل علامة الحذف.
- الزر والشاشة يتطلبان صلاحية `devices view`. نقل أو استبدال النتائج يبقى خاضعاً لصلاحية `medical reports update` وقواعد التطبيق الحالية. حالة **تم نقل النتائج** لا تعني اعتماد التقرير الطبي.
- إذا تعذر التحديث تظهر رسالة بأن البيانات المعروضة قديمة مع إمكانية إعادة المحاولة. الاستجابة القديمة لبحث سابق لا تستبدل نتائج البحث الأحدث.

## النشر والتحقق

التحديث يتطلب نشر الواجهة والخلفية معاً، ولا يحتاج ترحيلاً لقاعدة البيانات. لا يغيّر بروتوكولات الاتصال، استقبال الأجهزة أو محللات ASTM/HL7 أو المطابقة والنقل في الخلفية.

اختبار قاعدة البيانات: `php artisan test --filter=DeviceResultsInboxTest` من مجلد `backend`؛ واختبار `BridgeResultsTest` يغطي الاستقبال والمطابقة والنقل والاستبدال الحالية. يشملهما فحص MariaDB في GitHub Actions.

اختبار الواجهة: تشغيل Vite من `frontend` ثم `node tests/device-results.browser.mjs` بعد تثبيت Playwright وChromium. يستعمل مكونات البرنامج الفعلية مع بيانات مرضى تجريبية، ويفحص الاختصار والتفاصيل والبحث والترقيم والصلاحيات والتحديث والأخطاء وشاشات الهاتف. لقطات الاختبار تُرفق بتشغيل GitHub Actions الخاص بهذه الشاشة.
