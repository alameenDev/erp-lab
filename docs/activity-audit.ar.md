# سجل النشاط المفصّل

تفتح الصفحة من «سجل النشاط» (`/activityLogger`) بصلاحية `activities view`. تشمل السجلات اسم المنفّذ، التوقيت، نوع الإجراء، حالته، الفاتورة والباركود والمريض عند ارتباط الحركة بفاتورة. زر التفاصيل يعرض الحقول قبل وبعد، مع بيانات العملية الكاملة. التصدير CSV متوافق مع Excel ويشمل جميع النتائج المطابقة للفلاتر، مع صف لكل حقل تغيّر.

## ما يُسجّل

- نقرات أزرار الواجهة الداخلية للمستخدم المسجّل، حتى الأزرار التي تفتح نافذة أو تبدأ طباعة/تنزيل. «تم الضغط فقط» لا تعني نجاح تنفيذ العملية.
- عمليات النظام التي تنشئ أو تعدّل أو تحذف نماذج البيانات، مع مقارنة حالة قاعدة البيانات قبل الطلب وبعده. الطلبات الفاشلة مسجّلة بشكل منفصل عن التغييرات المحفوظة.
- الفاتورة كاملة: التحاليل، الزروع، الكروبات، الباقات، النتائج المتداخلة، الملاحظات، المرفقات والتسديدات. تؤخذ نسخة قبل العمليات حتى لا تختفي تفاصيل العناصر بعد حذفها أو تحديثها الجماعي.
- تحديثات نتائج الأجهزة تمر بنفس التدقيق، وتظهر باسم الجهاز مع المختبر والفاتورة.
- إعدادات التحاليل والكروبات والباقات تشمل العلاقات المعروفة (التحاليل التابعة، النطاقات المرجعية والأسئلة)، وتتبع البيانات الأخرى أحداث نماذج التطبيق. إذا أُضيف مستقبلاً تحديث جماعي مباشر يتجاوز نماذج التطبيق خارج الفواتير، يجب إضافة نسخة قبل/بعد للكيان المعني إلى `AuditSnapshot`/`AuditTrail`.

تُربط نقرة الزر بطلب النظام بواسطة معرّف حركة. يرسل العميل اسم الزر والصفحة فقط؛ القيم القديمة والجديدة ونتيجة الحفظ تُستخرج من الخادم. نقرات الواجهة تُرسل بأفضل جهد عند توفر الاتصال؛ تغييرات البيانات لا تعتمد عليها. فتح WhatsApp يُسجّل بدء المشاركة وليس إثبات تسلّم الرسالة.

## الصلاحيات والخصوصية

قراءة القائمة والتفاصيل والتصدير تتطلب الصلاحية نفسها، وبحدود المختبر. المدير العام يستطيع مراجعة الجميع. كلمات المرور والمفاتيح والرموز وروابط الدخول العامة محجوبة. لا يلتقط مسجّل الأزرار محتويات حقول الإدخال أو أجسام طلبات الشبكة. لا توجد واجهة لتعديل أو حذف السجلات.

السجلات القديمة تبقى متاحة. تعرض الصفحة التفاصيل التي كانت مخزّنة فيها فعلياً؛ لا يمكن إعادة بناء قيم لم تُسجّل في الماضي. المقارنة المحسّنة تبدأ بعد نشر هذا التحديث وتشغيل الترحيل.

## النشر والتحقق

يشغّل سكربت Hostinger المعتاد الترحيل `2026_10_05_000001_add_detailed_activity_indexes` قبل نشر الواجهة. يضيف أعمدة وفهارس إلى `activity_log` دون إزالة السجلات الحالية.

الاختبارات: `ActivityAuditTest` على MariaDB، وفحص المتصفح `frontend/tests/activity.browser.mjs`. تشمل تغيير النتائج عبر upsert، حذف الفاتورة وعناصرها، التسديد والإرسال، الفشل والتراجع، عزل المختبرات، حجب الأسرار، التصدير والفلاتر، وربط الأزرار بالطلبات.
