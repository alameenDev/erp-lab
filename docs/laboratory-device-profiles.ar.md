# إعداد الأجهزة لكل مختبر

ينشر التحديث من PR #29 مرة واحدة للخادم والواجهة المبنية معاً. لا يتطلب هذا الجزء ترحيلاً جديداً؛ تحفظ الخيارات في connection_config الموجود لكل سجل LabDevice. إصدار جسر الخادم السابق وترحيله ما زالا متطلباً أساسياً. إعداد جهاز جديد من الأنواع المدعومة لا يتطلب تعديل ملفات الخادم.

| Laboratory | Analyzer Model | CBC Interface Code | Protocol |
|---|---|---|---|
| مختبر الفرات | Beckman Coulter DxH 500 | 12345678 | ASTM LIS2-A2 |
| مختبر العاصمة | Nipigon NP-21H | 12345678 | HL7 2.3.1 / MLLP |

هذا جدول الإعداد المطلوب، وليس إثباتاً بأن سجلات الإنتاج عُدلت. لم يتم تعيين أسماء مختبرات أو معرفاتها بشكل ثابت داخل الكود، ولم تتغير سجلات الإنتاج.

## الإعداد من الواجهة

1. افتح الأجهزة ثم إضافة. مدير النظام يختار المختبر بالاسم والمعرف؛ مستخدم المختبر يرى مختبره فقط.
2. اختر Analyzer Model، وأدخل CBC Interface Code المطابق للتحليل في ذلك المختبر. الافتراضي 12345678.
3. اختر Result Handling: تعبئة مسودة الفاتورة حسب الباركود، أو الحفظ في الوارد للمراجعة والتطبيق اليدوي.
4. أدخل Analyzer IP Address وHost Port لتوثيق الربط. يجب مطابقتها مع إعدادات برنامج الكمبيوتر والجهاز؛ حفظها في الويب لا يعيد برمجة الجهاز أو الكمبيوتر عن بُعد.
5. احفظ واستخدم API Token الناتج في نسخة برنامج الربط المطابقة للموديل في كمبيوتر المختبر. لا تشارك مفتاح الفرات مع العاصمة.
6. CBC يبقى بأربعة أعمدة إنجليزية: Test / Result / Unit / Reference Range، والعنوان الكامل Complete Blood Count (CBC). النتائج مسودات للمراجعة ولا تُرسل للمريض تلقائياً.

## الحماية والسلوك

- مفتاح API يحدد سجل الجهاز ومختبره؛ الحمولة لا تختار مختبراً آخر.
- الاستقبال يرفض اختلاف الموديل عن إعداد الجهاز، وتطبيق الوارد يعيد التحقق من الموديل والباركود.
- نفس الباركود في مختبرين لا يربط النتائج بينهما.
- لا يمكن نقل ملكية سجل جهاز قائم لمختبر آخر حفاظاً على نتائج وتوكن ذلك السجل؛ يُنشأ سجل مستقل.
- الأجهزة القديمة التي لم تُضبط لها هذه الخيارات تحتفظ بسلوك DxH 500 وكود 12345678 والتعبئة التلقائية للمسودة.
- حفظ تعديل جزئي مثل عنوان IP يحتفظ بالموديل والكود وطريقة الإدخال وبقية إعدادات الاتصال السابقة.
- لا تُستبدل النتائج السابقة أو التقارير المعتمدة؛ تبقى النتيجة الجديدة في الوارد للمراجعة.
- تعطيل الإدخال التلقائي لا يمنع الاستلام والتخزين. يستطيع موظف يملك صلاحية تعديل النتائج تطبيقها يدوياً.
- الموديلات المدعومة حالياً في جسر CBC: DxH 500 وNP-21H. موديل ببروتوكول غير مدعوم يحتاج إضافة دعم واختبار قبل اختياره.

## النشر والاختبار

انشر جميع ملفات PR #29 عبر مسار نشر المشروع المعتاد، وابنِ واجهة frontend، ثم نفّذ `php artisan optimize:clear` داخل backend. لا تستخدم حزمة server-update القديمة ذات الملفين لهذا الإصدار.

اختبر على جهاز العاصمة إرسال عينة اختبار بباركود فاتورة CBC في مختبر العاصمة، وتحقق من وصول 21 نتيجة وبقائها مسودة. تحقق من عدم تغير نتيجة بنفس الباركود في مختبر الفرات. اختبارات قاعدة البيانات تتضمن هذا السيناريو، لكن يلزم التحقق الفعلي بعد النشر.
