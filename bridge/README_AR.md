# Digital Lab Bridge — DxH 500

وسيط بسيط يعمل على حاسبة المختبر: استقبال الجهاز عبر Ethernet، تحليل النتائج، حفظ محلي قبل ACK، ثم رفع تلقائي إلى سيرفر برنامج المختبر. لا يحتاج اسم مستخدم MySQL أو كلمة مرورها.

## قبل التشغيل الأول

يجب نشر تحديث السيرفر المرفق بهذا الفرع وتشغيل migration الجديد أولاً؛ الإصدار القديم من الموقع لا يدعم تأكيد الحفظ ومنع التكرار المطلوبين. تفاصيل النشر في `docs/DXH_BRIDGE_DEPLOYMENT.md`.

1. من الموقع افتح «الأجهزة» وأضف جهاز DxH 500 بنوع اتصال TCP، وانسخ مفتاح API الذي يظهر بعد الحفظ. ضعه في الوسيط على حاسبتك فقط. إذا نسيت المفتاح استعمل توليد مفتاح جديد للجهاز نفسه.
2. أغلق أدوات الاستقبال السابقة حتى لا تتنافس على المنفذ 5001.
3. افتح `DigitalLabBridge.exe` من حزمة Windows. لا يتطلب Python. إذا تستعمل ملفات المصدر افتح `START.cmd` بعد تثبيت Python 3.10+ مع Tkinter.
4. شاشة الإعدادات واحدة:
   - عنوان API: `https://lightpink-badger-650079.hostingersite.com/api`، راجعه إذا تغير عنوان موقعك.
   - مفتاح الجهاز: من صفحة الأجهزة داخل موقعك.
   - IP الحاسبة: `0.0.0.0`، يعني الاستماع على بطاقات الحاسبة. ليس عنواناً يوضع داخل الجهاز.
   - IP جهاز التحليل: `192.168.1.10` حسب الربط الذي نجح.
   - المنفذ: `5001`، يطابق Host Port داخل الجهاز.
   - حقل العينة: `2` يعني أول مكوّن في O-2، أو `3` لأول مكوّن في O-3. لا تغيّره دون مطابقة باركود حقيقي من الجهاز مع الفاتورة.
5. اضغط «فحص السيرفر وحفظ الإعدادات» ثم «تشغيل». بعد حفظ الإعدادات يمكن استقبال الرسائل أثناء انقطاع الإنترنت؛ يعاد إرسالها عند عودته.

داخل جهاز التحليل: Host IP هو IP الحاسبة الذي نجح سابقاً، Enable Host مفعّل، Ethernet مختار. لا تغيّر عنوان الجهاز إلى عنوان السيرفر الخارجي. اتصال الجهاز محلي، واتصال الوسيط بالسيرفر HTTPS.

## كيف أعرف أنه نجح؟

- «حُفظت محلياً» تعني البيانات موجودة في صف الانتظار فقط.
- «تأكد الحفظ بالسيرفر» مع رقم سجل تعني أن السيرفر أكد تخزين الرسالة نفسها.
- افتح الموقع ← الأجهزة ← النتائج الواردة ← التفاصيل. تُعرض القيم، الوحدات، المدى، العلامات، تعليقات الجهاز والرسالة الأصلية.
- عند انقطاع الإنترنت ترتفع الرسائل المنتظرة ثم تنخفض بعد عودته. نفس الرسالة لا تنشئ سجل استقبال جديداً عند إعادة المحاولة.
- أخطاء 401/403: تحقق من مفتاح الجهاز. 404: تحقق من نشر تحديث السيرفر وعنوان API. 409: هوية الجهاز أو محتوى الرسالة متعارضان. 422: الرسالة تحتاج فحصاً. لا تُحذف هذه الرسائل؛ صحّح المشكلة ثم استعمل «إعادة محاولة الإرسال».
- رسائل غير مكتملة/غير قابلة للتحليل تبقى محلياً للمراجعة ولا تُرسل كأنها نتائج صحيحة.

## ربط المريض والفاتورة

الموقع يطابق `specimen_barcode` مع `invoices.barcode` داخل مختبر الجهاز فقط. يجب إدخال/مسح باركود الفاتورة في حقل Sample ID بالجهاز ثم التأكد من أن O-2 يحمله. لا توجد مطابقة بأسماء المرضى ولا تخمين رقم المريض من رقم تشغيل الجهاز.

إذا لم توجد فاتورة مطابقة تبقى الرسالة محفوظة بحالة pending. إن طابقت تصبح matched، لكن **هذا الإصدار ينقل الرسائل إلى صندوق نتائج الأجهزة بقاعدة البيانات ولا يملأ أو يعتمد نتائج الفاتورة تلقائياً**؛ نحتاج تأكيد الباركود وخريطة الفحوصات/مكوّنات CBC أولاً. زر التطبيق لهذه الرسائل محجوب من السيرفر حتى لا تضيع تحذيرات الجهاز أو تدخل الفحوصات البحثية في تقرير المريض.

تعليقات Lyse Expired وSuspect Diff تُحفظ وتظهر كما وردت. الأكواد التي تبدأ بـ @ معلّمة بحثية. لا يقدم البرنامج تفسيراً طبياً أو تحويل وحدات.

## التشغيل والحفظ

- أبقِ البرنامج والحاسبة يعملان لاستقبال الجهاز. خيار التشغيل التلقائي يعني عند فتح البرنامج، وليس تثبيت خدمة Windows. لإطلاقه مع دخول Windows يمكن وضع اختصار له في مجلد Startup الخاص بمستخدم الحاسبة.
- إعدادات ومفتاح الجهاز والصف المحلي في `%LOCALAPPDATA%\DigitalLabBridge`، وزر داخل البرنامج يفتح المجلد.
- المفتاح محفوظ محلياً ضمن settings.json. البيانات المحلية غير مشفرة بواسطة التطبيق؛ احمِ حساب Windows ومجلد البيانات. لا ترسل هذا المجلد أو المفتاح علناً.
- النسخة الحالية لجهاز DxH 500 واحد. لا تشغّل أدوات متعددة على المنفذ نفسه.
- لا تغيّر السيرفر أو هوية الجهاز بوجود رسائل غير مرسلة؛ التطبيق يمنع إعادة توجيهها إلى مختبر آخر.
- ملفات بيانات التجربة في المصدر منزوعة الهوية، ولا تحتوي اسم المريض أو معرف التشغيل الحقيقي المرسل في المحادثة.

## اختبار القبول

بعد نشر التحديث: جرّب عينة معلومة، طابق الباركود والنتائج مع شاشة الجهاز، ثم أعد إرسال نفس الرسالة، وجرّب انقطاع الإنترنت واستعادته. بعد الإغلاق وإعادة الفتح تأكد من بقاء الرسائل. اختبارات التطوير لا تُغني عن هذه المطابقة على جهازك.
