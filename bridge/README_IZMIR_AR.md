# Izmir — Boule BM850 CBC Bridge

هذه النسخة مخصصة لرسالة BM850^HL7MW / HL7 2.7 الملتقطة في مختبر Izmir.

## التشغيل
1. ادمج تحديث BM850 وانشره على سيرفر البرنامج أولاً.
2. داخل حساب مختبر Izmir ← الأجهزة: أضف جهازاً أو عدّل جهاز المختبر، واختر Boule BM850 (Izmir). كود ربط CBC هو 12345678 ما لم يكن للمختبر كود آخر. انسخ مفتاح API الخاص بهذا الجهاز.
3. شغّل DigitalLabBridge-Izmir-BM850.exe. النسخة مستقلة ولا تحتاج Python. بديل المصدر: Python 3.12 ثم START_IZMIR.cmd.
4. API URL الافتراضي https://lightpink-badger-650079.hostingersite.com/api قابل للتغيير. ألصق مفتاح الجهاز في API Token. لا تستخدم مفتاح مختبر آخر.
5. IP الجهاز الافتراضي 192.168.137.85 بحسب الاتصال الملتقط. الاستماع على 0.0.0.0. المنفذ الافتراضي المقترح 5600؛ اللوج لا يبين منفذ السيرفر الفعلي، لذلك طابقه مع منفذ LIS في الجهاز أو غيّرهما إلى نفس الرقم.
6. في LIS بالجهاز ضع IP الحاسبة الفعلي، وليس 0.0.0.0، ونفس المنفذ. اسمح للبرنامج بالاستقبال ضمن شبكة المختبر في Windows Firewall.
7. اضغط فحص السيرفر وحفظ الإعدادات، ثم تشغيل. أغلق برنامج اختبار الشبكة إذا كان يستمع على المنفذ نفسه.
8. أرسل عينة اختبار ذات باركود فاتورة موجودة داخل Izmir. يجب ظهور ACK AA بعد الحفظ المحلي ثم تأكيد الحفظ بالسيرفر. راجع النتائج الواردة ثم مسودة CBC.

## المطابقة والنتائج
- المطابقة من OBR-4 فقط كنص؛ الأصفار في البداية محفوظة. OBR-3 رقم تسلسل الجهاز وليس الباركود. لا تتم المطابقة بالاسم.
- 22 نتيجة رقمية بأكواد الجهاز ووحداته ومجالاته كما أرسلها. RDWR/RDWA وLYMA/LYMR وGRNA/GRNR تبقى كما وردت دون تخمين تسميات أخرى.
- الحالة P تبقى preliminary وتظهر رسالة مراجعة؛ لا تتحول إلى نتيجة نهائية تلقائياً.
- بيانات HGRAM الحقيقية محفوظة مع بيانات الطلب والرسالة الأصلية في النتائج الواردة؛ هذا التحديث لا يضيف رسومات جديدة إلى التقرير.
- ACK AA يعني الحفظ في قائمة الإرسال المحلية، وليس اعتماد التقرير أو نجاح التسليم للسيرفر. انقطاع الإنترنت يعيد المحاولة تلقائياً.
- لا تستبدل النسخة نتائج سابقة أو تقارير موقعة/مرسلة، ولا تطابق فاتورة مختبر آخر.
- قاعدة الانتظار والإعدادات في %LOCALAPPDATA%\DigitalLabBridge-Izmir-BM850. لا تحذفها عند التحديث.
- غيّر IP/API من الواجهة: إيقاف، تعديل، فحص وحفظ، تشغيل. لن تنقل النسخة بيانات معلقة إلى وجهة أخرى.

## اختبار القبول
تحقق من تطابق الباركود و22 قيمة والوحدات والمجالات مع شاشة الجهاز. أعد إرسال العينة نفسها للتحقق من عدم تكرارها. اختبر قطع الإنترنت وإعادته والتحقق من التسليم. اعتماد الجهاز الفعلي يحتاج هذا الاختبار بعد تحديث السيرفر.
